Project 19: Order-Informed Domain Generalization for Rotating-Machinery Fault Diagnosis

Project Overview

This project investigates whether speed-informed signal normalization improves rotating-machinery fault classification under unseen operating conditions.

It also evaluates whether a consistency-learning objective provides additional improvements.

Research Question

Does speed-informed signal normalization improve fault classification at unseen rotational speeds compared with raw vibration-signal learning, and does an additional consistency objective provide further improvement?

Dataset

Paderborn University Bearing DataCenter.

Models

Raw CNN

Order CNN

Order CNN + Consistency
